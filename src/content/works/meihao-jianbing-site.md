> 這是示範作品。「美好煎餅」是虛構店名，地址、電話與價格都是編的，不是客戶案子，也還沒有實際上線給任何店家使用。照片來自 Unsplash，可免費商用；其中一張天津街頭照片的招牌文字改成了繁體。

小吃店的網站常常只有一張菜單照片和地址。客人想知道的其實是：這家在做什麼、哪一款推薦、現在去還有沒有、能不能先訂。

這個 Demo 把一間煎餅果子店當成精品品牌來介紹：**大圖說故事，菜單講清楚，最後讓客人自己算好再訂。**

## 打開看看

[美好煎餅 Demo](/demos/meihao-jianbing/)：電腦和手機都能看，往下捲到最後可以試用點餐試算。

## 頁面結構

| 區塊 | 內容 |
|---|---|
| 開場 | 一份煎餅果子的滿版照片，標語「一捲，六百年」 |
| 什麼是煎餅果子 | 一段介紹，加上一份裡面有什麼（綠豆餅皮、蛋、薄脆、生菜…） |
| 現場 | 鐵板攤餅與醬料的照片，說明現點現做 |
| 綠豆餅皮 | 鐵板上攤開的餅皮，捲動時以圓形展開 |
| 薄脆 | 一疊現炸薄脆，從攤子照片裁切後合成到深色背景 |
| 從路邊攤開始 | 天津街頭煎餅果子攤的照片 |
| 菜單 | 大份、小份、甜點、飲料，推薦口味用 ◆ 標示 |
| 加料 | 紅殼蛋照片，列出可加的配料 |
| 預訂 | 營業時間、賣完即收的說明、點餐試算 |

## 做了什麼

- **點餐試算**：選大份或小份，口味清單跟著換；勾選加料、調整數量，下方即時顯示品項摘要與合計。換份量時會保留同名口味。
- **照片動態**：每張大圖捲動時緩慢推近；餅皮那一段用圓形遮罩隨捲動打開，像麵糊在鐵板上抹開。
- **白霧轉清**：每張大圖進入畫面時，先蓋著一層半透明白霧，捲到位置才清楚，模仿精品官網的照片浮現效果。
- **營業資訊放在預訂旁邊**：賣完即收、公休日、不吃的配料要先說，都放在客人下單前會看到的位置。

## 設計上的考量

- **字放得下、看得清楚**：大圖上的文字底下有漸層暗部，再加一點文字陰影，淺色照片上也讀得到。
- **沒有照片的品項**：甜點和飲料先用色塊卡片標示「照片準備中」，不拿其他照片假裝。
- **減少動態效果**：系統設定「減少動態效果」時，關掉推近、展開與平滑捲動，內容照常顯示。

## 可以怎麼用在店家

早餐店、飲料店、便當店都能用同一套結構。需要準備的是店家自己的幾張好照片和一份菜單，點餐試算可以再接 LINE 官方帳號或 Google 表單，讓訂單真的送到店家手上。
