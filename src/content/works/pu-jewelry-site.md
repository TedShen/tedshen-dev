> 這是示範作品。「璞」是虛構品牌，作品、價格、門市與數據都是編的，不是客戶案子，也還沒有實際上線給任何品牌使用。照片來自 Unsplash，可免費商用。

精品珠寶的官網很少放大量文字。它們靠的是節奏：一張大圖、一句話、一個按鈕，再往下一張。訪客不是來比價的，是來感受這個品牌值不值得走進門市。

這個 Demo 把同樣的節奏用在一個台灣品牌上：**花蓮的玉，南方澳的紅珊瑚。**

## 頁面結構

| 區塊 | 內容 |
|---|---|
| 頁首 | 置中的品牌字「璞」，捲動後自動縮小 |
| 開場 | 綠色蛋面寶石，標題「山海之石」 |
| 品牌短句 | 石頭不說話，但記得山和海 |
| 玉鐲 | 一排排玉鐲的滿版照片 |
| 紅珊瑚項鍊 | 海邊配戴紅珊瑚項鍊的照片 |
| 精選作品 | 四件作品卡，含材質與價格 |
| 腕錶 | 白色錶盤特寫 |
| 品牌故事 | 工坊與工時數字，配一張手工打磨的照片 |
| 預約鑑賞 | 姓名、門市、日期、想看的作品 |

## 做了什麼

- **白霧浮現**：每張大圖進入畫面時先蓋著一層模糊的白霧，捲到位置才變清楚，像照片慢慢對焦。
- **照片推近**：大圖和作品卡隨捲動緩慢縮放，讓靜態照片有一點呼吸感。
- **頁首縮小**：品牌字一開始放大置中，捲動後縮小，讓出版面給內容。
- **預約鑑賞表單**：預設日期為三天後，送出後在頁面上顯示確認訊息（示範用，不會送出）。

## 設計上的考量

- **文字少、留白多**：每個區塊只有一個標題、一兩句說明和一個按鈕，字數刻意壓低。
- **大圖上的字看得清楚**：照片底部加漸層暗部，開場則把寶石放在右側，文字放在左側的淺色空白處。
- **手機版**：導覽縮成一行、作品卡改兩欄，開場文字改到下方並加淺色底。
- **減少動態效果**：系統設定「減少動態效果」時，關掉白霧、推近與平滑捲動，內容直接顯示。

## 可以怎麼用在品牌

珠寶、手錶、香水、高價工藝品都適合這種結構。重點是準備幾張質感好的大圖，文案反而要少。預約表單可以再接 Google 試算表或 LINE 官方帳號，讓門市直接收到預約。
