# 生產日報自動彙整（Python）

把每台機台匯出的 CSV 整理成一份 Excel 日報：總覽、班別、停機原因、異常清單、原始資料。
自有作品／示範，說明在 https://dev.tedshen.link/works/production-daily-report/

## 快速試跑

```bash
pip install openpyxl
python3 make_sample.py                       # 產生三台機台的範例資料到 sample/
python3 daily_report.py --input sample --date 2026-10-29
python3 -m unittest -v                       # 9 項測試
```

## 輸入格式

一台機台一個 CSV，檔名開頭是機台名稱（`M01_20261029.csv`）。標題列順序不限，常見英文標題也認得：

| 欄位 | 必填 | 也認得 |
|---|---|---|
| 時間 | ✔ | 日期時間、timestamp |
| 投入數 | ✔ | 投入、input |
| 良品數 | ✔ | 良品、good、ok |
| 不良數 | ✔ | 不良、ng、defect |
| 停機分鐘 | | 停機時間、downtime |
| 停機原因 | | 原因、reason |
| 工單、品號 | | work_order、part_no |

- 編碼：UTF-8 或 Big5（cp950）都可以。
- 日期 `2026/10/29 08:00`、`2026-10-29 08:00` 都可以。
- 空白列略過；看不懂的列不會中斷，會列進「異常清單」。

## 規則

- 班別：早班 08:00–20:00，夜班 20:00–隔天 08:00，夜班算在開始那天。
- 異常：良率低於標準（預設 97%）、單筆停機超過上限（預設 60 分鐘）、停機沒填原因、良品＋不良≠投入。
- 稼動率 =（班別計畫時間 − 停機）÷ 班別計畫時間，一班預設 12 小時。

參數：`--min-yield 0.98 --max-downtime 30`。

## 可以延伸成

- 每天固定時間自動執行，報表寄到信箱或推到 LINE
- 直接讀機台資料庫或共享資料夾，不用手動匯出
- 加週報、月報與趨勢圖
